# v3.17.0

- Registry-only delta. No schema or OpenAPI change.
- OD-028 (yeni karar, v3.17): tarayıcı oturumunun (OIDC Authorization Code + PKCE ile giriş) TripRequest'e ait operasyonlara nasıl erişeceği. v3.16 PLT-AUTH-001 yetki retrofit'i (od_impact ADR-010 blocked_pending_auth_task) sonrası bu operasyonlar yalnız `bearerAuth` kabul eder; tarayıcı akışları Bearer token taşımadığından 401 alıyordu. Sözleşme yalnız "kullanıcıya dönük istemciler Authorization Code + PKCE kullanır; istemci entegrasyonu ayrı görevdir" diyordu (v3.16 x-token-validation.clients, od_impact ADR-010 resolution.clients). Karar önce OPEN olarak üç seçenekle (A web adaptörleri, B tarayıcıda Bearer token, C web akışları kapalı) kaydedildi.
- OD-028 RESOLVED (user, 2026-10-17) - Seçenek A onaylandı: TripRequest'e ait 12 operasyon (OP-startFlightSearch, OP-pollFlightSearch, OP-get/select/reconfirmTripRequestFlight, OP-startAccommodationSearch, OP-pollAccommodationSearch, OP-get/select/reconfirmTripRequestAccommodation, OP-startPoiDiscovery, OP-pollPoiDiscovery) aynı yol, metot, şema ve iş semantiğiyle `/web-api/v1` önekli web kanalından sunulur. Principal yalnız SessionWebPrincipalResolver (tamamlanmış tarayıcı OIDC girişi) ile alınır, oturum yoksa 401 RC-AUTHN-REQUIRED; POST/PUT Laravel CSRF doğrulamasından geçer (geçersiz/eksik token 419, kod null - GAP-ERR-UNREGISTERED-001, Türkçe mesaj); sahiplik TripRequestOwnership ile /api/v1 ile aynı sırada (404 -> 403, owner'sız eski kayıt 403) ve yan etkilerden önce denetlenir. API Bearer token'ı üretilmez/saklanmaz/tarayıcıya verilmez; PrincipalRef ve owner alanları yanıtlarda yer almaz. OP-getTripRequest web kanalına eklenmez (tarayıcı çağırmaz); teklif ve bağımsız POI operasyonları değişmez. Yeni tablo veya owner sütunu yok. Ayrıntı: `registries/od_impact.yaml` OD-028.
- `/api/v1` Bearer-only kalır; ADR-010 çözümlenmiş kısmı ve PLT-AUTH-001 kuralları değişmez.
